# 改写提示词：问题 → 2~3 路检索式

用途：`rewrite` 节点。**当前实现以词典改写为主**（`backend/tools/kb_tools.py`
的 `expand_queries()` + `config/glossary.yaml`），本文件是同一任务的模型侧口径；
词典先跑，模型只作兜底（开发文档 4.4.2：能用固定流程表达的，不交给模型决定）。

## 输入

```
{{question}}
```

可用的术语表片段（规范词 → 同义词）：

```
{{glossary}}
```

## 任务

把用户问题改写成 2~3 路可直接检索的检索式，输出 JSON 数组，不要输出解释：

```json
["原问题（保留原样，避免改写引入噪声）",
 "术语归一后的检索式（把口语/英文说法替换成规范术语）",
 "关键词式检索式（设备型号 + 部件 + 现象 + 关键名词，去掉疑问词与虚词）"]
```

## 规则

1. **第一路必须保留原始问题**：改写可能引入噪声，原问题这一路是兜底。
2. 术语归一：刻蚀机/Etcher/蚀刻机 → 刻蚀机；腔压/腔体压力 → 真空度；
   O型圈/密封圈 → O-ring；PM 周期/保养周期 → 清洗周期。
3. 第三路只保留名词性关键词，**不要**包含「怎么」「如何」「为什么」「请问」。
4. 不要发明知识库里可能不存在的术语；不确定就少改。
5. 输出必须是合法的 JSON 数组，元素为字符串，2~3 个元素。
