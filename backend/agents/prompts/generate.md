# 生成提示词：上下文 + 问题 → 带引用的答案

当前模式：**{{mode}}**（`qa` = 常规问答；`training` = 培训分层讲解，见下文模板选择）

上下文材料（唯一知识来源，`[n]` 为编号）：

```
{{context}}
```

用户问题：

```
{{question}}
```

## 回答步骤（内部执行，不要输出过程）

1. 判断上下文是否**足以**回答该问题。若不足以回答，直接走「未覆盖」分支（见下）。
2. 组织答案：每条结论只使用上下文中的原意，句末标注 `[n]`。
3. 自查：每个 `[n]` 必须存在；每个结论句都必须有引用；数值必须来自上下文。
4. 若问题问的是具体设备的参数或周期，而上下文只覆盖其他型号，**不要外推**：
   说明「知识库中未找到该型号的信息」并列出已有型号的材料。

## 模板选择

### 模式 `qa`（默认）

```
<直接结论或步骤清单，每条句末带 [n]>

依据：
- [n] 《文档名》 版本 第 X 页 章节 Y
```

参数类问题按「参数名：数值（单位）[n]」逐条列出。

### 模式 `training`（FR-09 培训分层讲解）

按新人培训的口径分三层，每层都要带引用：

```
**基础理解**：这条知识是什么、为什么重要。[n]
**操作要点**：按顺序做什么，每步一句。[n]
**常见误区**：现场容易做错的地方（必须有上下文依据，没有就写「上下文未涉及」）。[n]
```

## 未覆盖分支（重要）

当上下文不足以回答时，**只**输出下面这种形式，不要给出任何操作步骤或参数：

```
知识库未覆盖该问题，不给出具体操作步骤。
已检索到的相关材料：《文档名》 版本 第 X 页；……
建议：补充设备型号与现象描述，或转人工支持。
```
